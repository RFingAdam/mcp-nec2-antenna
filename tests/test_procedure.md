# MCP NEC2 Antenna - Test Procedure

## Prerequisites

### 1. Install NEC2C Solver
```bash
# Ubuntu/Debian
sudo apt install nec2c

# Verify installation
nec2c --version
```

### 2. Install MCP Server
```bash
cd /home/swamp/projects/github/mcp-nec2-antenna
uv pip install -e .
```

### 3. Add to Claude Code
```bash
claude mcp add nec2-antenna -- uv run --directory /home/swamp/projects/github/mcp-nec2-antenna mcp-nec2-antenna
```

## Test Cases

### Test 1: Create Half-Wave Dipole

**Purpose:** Verify basic antenna creation and dimension calculations

**Steps:**
1. Ask Claude: "Create a 2-meter band dipole antenna at 146 MHz, 10 meters height"

**Expected Results:**
- Tool: `nec2_create_dipole` called
- Returns antenna_id (UUID)
- Calculated length ≈ 0.975m (half-wave with 5% shortening)
- Success: true

**Validation:**
```
Expected length = (300/146) * 0.5 * 0.95 ≈ 0.975m
```

---

### Test 2: Create Yagi-Uda Antenna

**Purpose:** Verify multi-element directional antenna creation

**Steps:**
1. Ask Claude: "Create a 5-element Yagi antenna for 144 MHz"

**Expected Results:**
- Tool: `nec2_create_yagi` called
- Returns antenna with 5 elements (1 reflector + 1 driven + 3 directors)
- Expected gain estimate: ~13 dBi
- Success: true

---

### Test 3: Create Vertical with Radials

**Purpose:** Verify ground-plane antenna with multiple wires

**Steps:**
1. Ask Claude: "Create a 40-meter vertical antenna at 7.15 MHz with 8 radials"

**Expected Results:**
- Tool: `nec2_create_vertical` called
- Returns `calculated_height_m` ≈ 10.5m (quarter-wave)
- Returns `radials: 8`
- 8 radial wires at ground level
- Success: true

---

### Test 4: Create Full-Wave Loop

**Purpose:** Verify loop antenna geometry calculation

**Steps:**
1. Ask Claude: "Create a quad loop antenna for 14.2 MHz at 15m height"

**Expected Results:**
- Tool: `nec2_create_loop` called
- Returns `circumference_m` ≈ 21.1m (one wavelength)
- Returns `height_m: 15`
- 4-sided loop (quad configuration)
- Success: true

---

### Test 5: Create Inverted-V Dipole

**Purpose:** Verify inverted-V with droop angle calculation

**Steps:**
1. Ask Claude: "Create an inverted-V dipole for 7 MHz with 20m apex and 45 degree droop"

**Expected Results:**
- Tool: `nec2_create_inverted_v` called
- Returns `apex_height_m: 20`
- Returns `droop_angle_deg: 45`
- Returns `total_wire_length_m` ≈ 20.3m (half-wave)
- Returns `end_height_m` ≈ 12.8m (calculated from droop angle)
- Feed at apex
- Success: true

---

### Test 6: Run NEC2 Simulation

**Purpose:** Verify NEC2 solver execution and result parsing

**Steps:**
1. First create a dipole: "Create a dipole for 146 MHz"
2. Then: "Simulate this antenna and show me the impedance"

**Expected Results:**
- Tool: `nec2_simulate` called with antenna_id
- Frequency sweep: 131.4 - 160.6 MHz (±10%)
- Returns:
  - best_match with frequency, resistance, reactance, VSWR
  - Impedance at center frequency ≈ 72Ω + j0 (typical dipole)
  - VSWR < 2:1 near design frequency
- Success: true

**If NEC2C not installed:**
- Error message: "nec2c not found. Install with: sudo apt install nec2c"

---

### Test 7: Get NEC2 Card Deck

**Purpose:** Verify NEC2 input file generation

**Steps:**
1. Create any antenna
2. Ask Claude: "Show me the NEC2 card deck for this antenna"

**Expected Results:**
- Tool: `nec2_get_nec_cards` called
- Returns NEC2 format text with:
  - CM (comment) cards
  - GW (wire geometry) cards
  - GE (geometry end) card
  - EX (excitation) card
  - FR (frequency) card
  - RP (radiation pattern) card
  - EN (end) card

**Sample Output:**
```
CM 2m Dipole
CM Half-wave dipole at 10.0m height
CM Frequency: 146.0 MHz
CM Generated by mcp-nec2-antenna
CE
GW 1 21 -0.487500 0.000000 10.000000 0.487500 0.000000 10.000000 0.001000
GE 0
EX 0 1 11 0 1.000000 0.000000
FR 0 1 0 0 146.0000 0
RP 0 91 120 1000 0 0 2 3
EN
```

## Known Limitations

1. **Simulation requires nec2c:** The MCP server requires the external `nec2c` solver
2. **No persistence:** Antenna designs are stored in memory and lost on restart
3. **Simplified models:** Antenna templates use common approximations
4. **No ground effects tuning:** Real ground parameters not exposed in all tools
